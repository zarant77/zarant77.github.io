Kestrel Drift

×

Kestrel Drift is a custom-built drone simulation project focused on realistic control authority, altitude hold, gust modeling and payload drop validation. The entire physics stack is implemented without external engines, using a force-based motion model and a deterministic update loop.

Highlights
  • Custom quadrotor flight model (angle-mode pitch/roll + altitude hold)
  • Seed-based gusty wind system with overlapping envelopes
  • Force-based motion (acceleration → velocity → position)
  • Motor response, inertia and thrust compensation under tilt
  • Independent payload physics with quadratic drag and ballistic validation presets
  • Strict simulation/render separation (WorldState as single source of truth)
Tech
  • Fixed timestep simulation
  • Custom math utilities (vec2 / vec3 / deterministic RNG)
  • Action-based input binding system with runtime rebinding
  • Performance-oriented update loop
  • Debug instrumentation layer (OSD + telemetry overlay)
  • Localization system with audit tooling

Cat ’Em Up

×

A high-energy side-scrolling beat ’em up inspired by classic arcade machines and 80s neon culture. Players fight through fast-paced encounters driven by timing, positioning and impact, with a strong focus on clarity and responsiveness. Under the hood, the game is powered by a deterministic engine with decoupled rendering, demonstrating clean and reusable game system architecture.

Highlights
  • Deterministic game core (30Hz)
  • Snapshot + events rendering model
  • Multiple clients: Phaser (2D), Three.js (3D), CLI
  • Rendering fully decoupled from game logic
Tech
  • TypeScript
  • Phaser / Three.js
  • Engine-agnostic architecture
  • Performance-oriented update loop
