Privacy Policy

BattDeck Privacy Policy

Effective date: July 17, 2026

BattDeck is an Android application for managing battery packs, voltage levels, charge status, and usage order.

Data Collection

BattDeck does not collect, transmit, sell, or share personal data.

The app does not use user accounts, analytics, advertising SDKs, tracking SDKs, cloud synchronization, or remote servers.

Local Data Storage

BattDeck stores battery pack information locally on the user's device. This data may include:

  • battery pack names;
  • battery type;
  • voltage value;
  • charge percentage calculated from voltage settings;
  • active battery status;
  • battery order;
  • application settings such as minimum and maximum voltage.

This information remains on the user's device unless the user explicitly chooses to export, save, or share it.

JSON Import and Export

BattDeck allows users to export battery pack data to a JSON file and import it later.

Exported JSON files are created only when the user chooses to export them. The user controls where the file is saved and with whom it is shared. BattDeck does not automatically upload exported files anywhere.

Permissions

BattDeck may use Android system file picker or share sheet features to let the user import, export, save, or share JSON files.

These actions are initiated by the user. BattDeck does not request broad access to the device file system.

Data Retention and Deletion

Battery data is stored on the user's device until the user edits it, removes it, imports replacement data, clears app data, or uninstalls the app.

BattDeck does not keep a remote copy of user data.

Children's Privacy

BattDeck is not directed to children and does not knowingly collect personal information from children.

Changes to This Policy

This Privacy Policy may be updated from time to time. Updates will be published on this page.
